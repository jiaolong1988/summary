## 3. watchEffect 根据 captchaType 分发

[Verify.vue:120-135](vscode-webview://10tb6dvl59bnqrerfg2sjfhba4491u08mesup1pnbn6ep9s5rjra/src/components/Verifition/src/Verify.vue#L120-L135)



```ts
watchEffect(() => {
  switch (captchaType.value) {
    case 'pictureWord':   // 文字验证码
      verifyType.value = '3'
      componentType.value = 'VerifyPictureWord'
      break
    case 'blockPuzzle':   // 滑块（登录页默认用这个）
      verifyType.value = '2'
      componentType.value = 'VerifySlide'
      break
    case 'clickWord':     // 点选文字
      verifyType.value = ''
      componentType.value = 'VerifyPoints'
      break
  }
})
```

所以登录页传 `captchaType="blockPuzzle"`（[LoginForm.vue:110](vscode-webview://10tb6dvl59bnqrerfg2sjfhba4491u08mesup1pnbn6ep9s5rjra/src/views/Login/components/LoginForm.vue#L110)）→ `componentType` 变成 `'VerifySlide'`、`type='2'` → 动态组件实例化 VerifySlide 并注入 props。

const refresh = () => {

## 5. 子组件内部逻辑与事件回传

Verify.vue 只负责**渲染 + 透传 props + 暴露 show/close**，真正的取图、拖拽、校验都在 VerifySlide 里（`onMounted → init()` 自动开始）：



```
VerifySlide 挂载
  ├─ getPictrue() → getCode({captchaType})      取验证图片 + token
  ├─ 用户拖滑块 → end() → reqCheck({...})        校验位置
  ├─ 成功 → emit('success', { captchaVerification })
  └─ 失败/刷新 → refresh() → getPictrue() 重新取图
```

事件回传的关键在 [VerifySlide.vue:315](vscode-webview://10tb6dvl59bnqrerfg2sjfhba4491u08mesup1pnbn6ep9s5rjra/src/components/Verifition/src/Verify/VerifySlide.vue#L315)：



```ts
proxy.$parent.$emit('success', { captchaVerification })
```

`proxy.$parent` 就是外层 **Verify.vue 实例**，所以在它身上派发 `success` 事件 → 直接命中登录页在 `<Verify>` 上绑定的 `@success="handleLogin"`（[LoginForm.vue:77](vscode-webview://10tb6dvl59bnqrerfg2sjfhba4491u08mesup1pnbn6ep9s5rjra/src/views/Login/components/LoginForm.vue#L77)）。Verify.vue 不拦截也不转发，只是作为子组件事件向外传播的"宿主"。同理 `error`、`ready` 事件也一样向外冒泡。

## 一句话总结



```
LoginForm（传 captchaType + @success + ref="verify"）
   └─ Verify.vue（分发器：watchEffect 选子组件、透传 props、暴露 show/closeBox/refresh）
        └─ VerifySlide（真正的滑块验证逻辑，内部调 getCode/reqCheck）
              └─ 成功时 proxy.$parent.$emit('success') → LoginForm 的 handleLogin
```
