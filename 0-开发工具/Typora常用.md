

# 快捷键

| 快捷键                        | 功能                                                         |
| ----------------------------- | ------------------------------------------------------------ |
| ==Shift + Tab==               | **减少缩进**                                                 |
| Ctrl + T                      | 插入表格                                                     |
| == 文字内容 ==   Ctrl+Shift+H | 高亮:typora 文件->偏好设置- > Markdown -> Markdown扩展语法，选中==高亮== |
| enter enter                   | 结束序列                                                     |
| enter tab                     | 子序列                                                       |
| :符号名称                     | 输入特定符号。例如（:one）:one:                              |
| shift+enter                   | 形式换行+实际换行=真正换行                                   |
| 两个空格                      | 实际换行+形式换行=真正换行                                   |

 

# 快捷键设置

1. 打开 Typora，依次点击 **文件 > 偏好设置 > 通用 > 打开高级设置**。

2. 用文本编辑器打开文件夹中的 *conf.user.json* 文件。

3. 添加以下代码：

   ```json
   "keyBinding": {
   	"Highlight": "Ctrl+Shift+H"
   }
   ```

4. 保存文件并重启 Typora。



# 关闭拼写检查

1. 打开Typora。
2. 点击菜单栏中的“文件”。
3. 选择“偏好设置”。
4. 在“编辑器”选项卡中，将“拼写检查”设置为“不使用拼写检查”。
